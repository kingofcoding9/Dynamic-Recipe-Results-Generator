How it works

The Omni-Recipe Studio parses your Bedrock Add-on `.zip` or `.mcaddon` file entirely in the browser. It links Recipes to Items, finds their Icons via texture definitions, and detects custom Crafting Tables via block tags.

Installation

  1. Download the Recipe Book System script.
  2. Place the file in your behavior pack's scripts/ folder.
  3. Ensure your manifest.json has the @minecraft/server-ui dependency.
  4. Import and call showRecipeBook(player) in your main script.
